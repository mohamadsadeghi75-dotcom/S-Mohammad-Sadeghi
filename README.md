# Mohammad Sadeghi — personal website

A responsive, dependency-free landing page made with HTML, CSS, and JavaScript.

## Preview
Open index.html in your browser. Keep the CSS, JavaScript, and assets folder beside it. No installation or build step is required.

## Publish to GitHub Pages
1. Extract this ZIP.
2. Create a GitHub repository (a public repository works with GitHub Free).
3. Upload the CONTENTS of the mohammad-site folder to the repository root. index.html must sit directly in the root, alongside styles.css, script.js, .nojekyll, and assets/.
4. In the repository, open Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), and save.
5. GitHub will provide the published URL once deployment finishes.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

All asset URLs are relative, so the page supports both username.github.io and username.github.io/repository-name/.

## Add your LinkedIn and email
At the top of script.js, put your actual LinkedIn profile URL and email into PROFILE. Contact links appear automatically once valid values are present. Your LinkedIn profile and email are configured. Do not put passwords or private information in these files; published source is public.

## Edit the page
- index.html: biography, expertise, and the Recent Work at Snapp Pay project cards.
- styles.css: colors, typography, layout, and mobile styles. Brand colors are defined at the top.
- script.js: mobile navigation, contact settings, and footer year.
- assets/: your two supplied photographs and the favicon.

The page uses local system fonts and no third-party tracking, font services, libraries, forms, or backend. Navigation and project disclosures remain usable with JavaScript disabled.
